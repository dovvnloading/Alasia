# Alasia: Lost Isles

**A dark, original, isometric action RPG for the web — currently in preproduction.**

> In Alasia, the machines that hold one island above the sea can do so only by lowering another. When the outer shore begins to fail, three trades of field-workers uncover the erased names of those whose homes were spent to protect the capital. The next allocation cannot be hidden.

**Status:** Documentation foundation, proposal v0.1 (13 November 2026). **No game has been implemented.** The name **Alasia: Lost Isles** is project-owned direction; all other world, narrative, class, balance, production and technical details are **working proposals**, not approved final canon.

## Creative direction

A rapid, weighty, high-readability, top-down 3D ARPG in a rain-cut, pre-industrial island society: close enough to the *genre* of Diablo III/IV and Path of Exile to deliver satisfying combat cadence, item discovery and threatening encounters; deliberately independent in its **world mechanics, class verbs, imagery, story, characters, terminology and interface**. We do not copy protected game art, UI layouts, enemy likenesses, narrative beats, names or skill implementations.

The founding law is **no shore rises for free**. An engineered network routes subsurface strain through a rare mineral. The law explains the physical crisis, economy, class professions, geography and the argument at the heart of the story. See the [creative constitution](docs/00-foundation/creative-constitution.md) before expanding any area.

## Process before implementation

1. Protect the world seed and challenge every downstream addition with a cause-and-effect explanation.
2. Challenge class identities in graybox before committing to expensive art production.
3. Test the narrative for chronology, economics, logistics, human motive, player agency and production feasibility.
4. Resolve **P0 unknowns** and pass **Gate G0** in the production document before opening an implementation milestone.
5. Start with **one playable, authored district on Orren**, not a huge content map.

A document marked **WORKING** is a deliberately testable direction, not a promise. Every proposed name and mechanic can be rejected. Art-ready and engineering-ready status require explicit review.
